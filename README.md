### 🔹 [Gestion de Alquiler de Maquinarias](https://github.com/SantyChQu/ProyectoAlquilerMaquinarias)
Descripcion:
Desarrollo grupal de una aplicación web
 para registrar y gestionar alquileres de maquinarias,
 Además contempla la gestión de usuarios/clientes que
 realizan los alquileres como el registro e inicio de
 sesion, y funcionalidades dedicadas a empleados y
 jefes del sistema

 Herramientas/Tecnologias usadas:
 Django,SQlite,Python,CSS,html

### 🔹 [Gestion de Biblioteca](https://github.com/SantyChQu/Gestion-Biblioteca-.NET)
Descripcion:
Desarrollo individual de una aplicación
 web para registrar y gestionar préstamos de libros,
 permitiendo a los usuarios (alumnos y profesores)
 realizar retiros, devoluciones, y administrar el catálogo
 de libros (alta, modificación y eliminación).
 
Herramientas/Tecnologias usadas:
#C,Blazor,Razor,SQlite,EntityFramework,html,CSS
